# Blub-Music
Blub is a easy linux cli music tool which streams music while being very lightweight

# TUTORIAL

1. cd into the folder where install.sh is at
2. Run the command Sudo bash install.sh
3. after that youre all set. you can delet the install.sh

# COMMANDS

blub --h :
  shows all the commands
blub --songs :
  opens list to all songs.
